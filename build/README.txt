Gestura v2 - Setup Instructions

1. Install the Virtual Camera Driver:
   Double-click and run "install_virtualcam_driver.exe" before launching the app.
   This is a one-time setup required to enable virtual camera outputs for Zoom, Teams, or Meet.

2. Launch Gestura:
   Open the "Gestura" folder and run "Gestura.exe".

System Requirements:
- Windows 10 or 11 (64-bit)
- OBS Studio (optional, but recommended for virtual camera output)
